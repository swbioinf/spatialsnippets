Dataset: IBD cosMX GarridoTrigo2023 - cluster annotation

Sarah Williams (QCIF)

Note: This document does not include a code snippet for running a specific test, rather it is an example of celltype annotation. While less explanetory than the snippets, this document is included with them as it might be a useful resource for tackling celltype annotation in the bioconductor ecosystem. For a seurat-based approach see the cluster labelling section from an intro to spatial (Seurat) workshop.

Following on from setting up the sfe object from the GarridoTrigo2023 IBD dataset, this doc generates some celltype labels for the clusters defined within. While some examples use the GarridoTrigo2023 broad celltypes (5x very broad categories) or their much more detailed celltype assignments (55x very specific types), some methods might be easier demonstrate with an intermediate classification level.

Marker genes

Following OSCA examples; https://bioconductor.org/books/release/OSCA.basic/marker-detection.html

marker_lists <- findMarkers(sfe, groups=sfe$cluster_code,
                            BPPARAM=MulticoreParam(workers=8) # run on 8 cores.
                            )
build_marker_summary_table <- function(marker_lists , the_group) {
  # Make a gene/target column from the rownames, and add the group so we can make one big concatenated table. discard pairwise results.
  tibble(cbind(cluster_code=the_group, rownames_to_column(as.data.frame(marker_lists[[the_group]][2:4]) ,var = "target" )))
}

marker_table <- bind_rows(lapply(FUN=build_marker_summary_table, X=names(marker_lists), marker_lists=marker_lists))
